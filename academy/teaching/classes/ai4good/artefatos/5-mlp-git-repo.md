# [5] artefato · mlp git repo

> **código no painel:** `mlp·c`  
> **pontuação total:** 10 pontos (5 itens de verificação · 2 pontos por item)

## descrição

implementação do zero de uma rede neural multicamadas (MLP), com interface interativa de experimentação e controle de hiperparâmetros.

## pontos de verificação

1. [ ] **subrepositório estruturado:** diretório do projeto isolado sob a pasta de código com seu próprio `CONTEXT.md` descrevendo objetivos e arquitetura.
2. [ ] **parametrização interativa:** rede neural multicamada configurável em tempo real (camadas, neurônios, taxa de aprendizagem, épocas e funções de ativação).
3. [ ] **particionamento de dados:** dataset baixado, padronizado e particionado explicitamente em conjuntos de treino (80%) e teste (20%).
4. [ ] **dinâmica de treinamento:** rotina completa de treino executando *forward pass* (propagação direta) e *backpropagation* (retropropagação com gradiente descendente).
5. [ ] **visualização de pesos:** interface com inspeção visual da atualização dos pesos sinápticos a cada época (exibição numérica e espessura das conexões).
