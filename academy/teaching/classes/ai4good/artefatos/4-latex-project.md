# [4] artefato · latex project

> **código no painel:** `pdf`  
> **pontuação total:** 8 pontos (4 itens de verificação · 2 pontos por item)

## descrição

infraestrutura de redação científica rigorosa, integrando compilação local via harness, sincronização com Overleaf e gerenciamento automatizado de literatura acadêmica.

## pontos de verificação

1. [ ] **compilação local:** ferramentas de compilação de `.tex` para `.pdf` funcionais no ambiente local, com o primeiro PDF compilado com sucesso via harness.
2. [ ] **integração overleaf:** conexão bidirecional estabelecida com projeto no Overleaf, registrando a primeira contribuição enviada diretamente pelo harness.
3. [ ] **pipeline de referências:** ferramentas de busca acadêmica com download de PDFs, OCR automático (zero-token) e pasta `refs/` estruturada com geração automática de metadados em `.yaml`.
4. [ ] **árvore de pesquisa:** módulo de pesquisa e habilidades (skills) adicionado ao workspace para apoio a leitura/revisão bibliográfica, formulação metodológica e redação técnica.
