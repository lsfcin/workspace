# Every Google grant a tool may hold, declared: the read scopes, the write scopes (- for none), and the CLI that consents to it (- for none yet). Read by core/tools/auth/gauth.py.
#
# A grant is a pair of tokens, ~/.config/workspace-<service>/ for reading and workspace-<service>-write/ for writing,
# and a read never borrows the write token: a credential that can write is only ever loaded for a write.
# A scope is written without its https://www.googleapis.com/auth/ prefix; several are joined by a comma.
# A service missing here is refused by gauth.auth, and its recovery falls back to naming the token path.
service	read	write	cli
calendar	calendar.readonly	-	tools/calendar/gcalendar
docs	documents.readonly	documents	tools/docs/gdocs
drive	drive.readonly	drive	tools/files/gdrive
forms	forms.body.readonly,forms.responses.readonly	forms.body,drive.file	tools/forms/gforms
gmail	gmail.readonly	-	tools/mail/gmail
sheets	spreadsheets.readonly	spreadsheets	-
slides	presentations.readonly	presentations	tools/slides/gslides
