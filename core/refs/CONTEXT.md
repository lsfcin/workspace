# References
> Captured references for the agent library — level-1 links in [REFS.md](REFS.md).

The grounding-and-doubt literature left on 2026-09-13 with the research that gathered it:
`academy/papers/back2dsl/refs/REFS.md`. A paper owns its own refs, and that one is no longer this library's question.

Two levels, the same split as a paper's `refs/`: [REFS.md](REFS.md) is the intake, and a ref promoted out of it becomes `<key>.yaml` here — the file that grows. Every judged ref carries a level marker (`[A]`/`[B]`/`[P]`/`[V]`/`[C]`) recording how much weight the claim holds — arXiv is easy to over-collect and is **not peer reviewed**, so the marker is what lets a later reader tell a citable finding from a provisional one at a glance. Level definitions and the citation discipline: [`SPECS.md`](SPECS.md).
