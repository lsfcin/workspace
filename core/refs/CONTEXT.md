# References
> Captured references for the agent library / workspace-os scaffold — tier-1 links in [REFS.md](REFS.md).

Every ref in [REFS.md](REFS.md) carries a tier marker (`[A]`/`[B]`/`[P]`/`[V]`/`[C]`) recording how
much weight the claim holds — arXiv is easy to over-collect and is **not peer reviewed**, so the
marker is what lets a later reader tell a citable finding from a provisional one at a glance. Tier
definitions and the citation discipline: [`SPECS.md`](SPECS.md).
