# slides
> The /slides tree: craft subskills, three second-level branches, the provider leaf and one yaml per ref.

<!-- routing:start -->
## Routing

| Subdirectory | Description |
|--------------|-------------|
| [`formats/`](formats/CONTEXT.md) | Children of formats.md: one file per content format a slide can carry. |
| [`narrative/`](narrative/CONTEXT.md) | Children of narrative.md: the arc (structure) and the scene (visual-story). |
| [`refs/`](refs/CONTEXT.md) | One yaml per reference the /slides subskills cite; schema of academy/papers/SPECS.md § Reference reviews, plus `level` and the web|tool|deck|talk types. |
| [`visuals/`](visuals/CONTEXT.md) | Children of visuals.md: one-idea, layout, typography, color-and-imagery. |

| File | Description |
|------|-------------|
| [`accessibility.md`](accessibility.md) | Contrast, minimum projected size, alt text, captions, colour never the only signal. |
| [`backup-and-qa.md`](backup-and-qa.md) | Backup slides for the questions you expect: shown when asked, never spoken. |
| [`formats.md`](formats.md) | Router: pick the format a concept needs, and combine at least 3 per concept (`SPECS-aulas.md` rule of 3). |
| [`gslides.md`](gslides.md) | Provider hand: read, preview and edit decks through the API. The craft is in [`../slides.md`](../slides.md). |
| [`narrative.md`](narrative.md) | Router: the deck's order, and telling it with images. Combining the two is the skill. |
| [`render-check.md`](render-check.md) | Render → critique → fix, at most two rounds: overlap, overflow, off-grid, small images. |
| [`speaker-notes.md`](speaker-notes.md) | What is said, not shown: the 3-line notes (`←` `●` `→`) and the script behind a sparse slide. |
| [`style-system.md`](style-system.md) | Lock colour, font, size and spacing tokens before any content, and hold every slide to them. |
| [`taste.md`](taste.md) | The judgement that opens and closes every deck: holds the context, arbitrates the other subskills, refines. |
| [`visuals.md`](visuals.md) | Router: how a slide looks. Combining idea, arrangement and appearance is the skill. |
| [`word-choice.md`](word-choice.md) | Text on a slide: assertion titles, noun phrases over prose, no read-aloud paragraphs. |
