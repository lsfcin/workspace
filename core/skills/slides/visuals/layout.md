# layout
> Grid, alignment, proximity, whitespace, header and footer positions.

Arrangement only; the tokens are `style-system`.

- A number or label never touches its element. An order number goes inside or beside its element, never at a crossing.
- A slide without a footer uses a layout without one, never a mask over it; the footer need not be on every slide.

Refs: `williams-crap` · `refactoring-ui`
