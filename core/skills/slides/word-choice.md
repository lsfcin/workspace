# word-choice
> Text on a slide: assertion titles, noun phrases over prose, no read-aloud paragraphs.

A title does two jobs, split: the message is an assertion beside the element it speaks about (once per build sequence); navigation is the title placeholder, drawn as a 1–3 word footer anchor. Never a traditional title across the top — nobody reads it; not even in a validation deck, so it never becomes habit.

Sentence level; the arc is `narrative`, letterforms are `visuals/typography`.

Refs: `alley2005` · `kosslyn2007`
