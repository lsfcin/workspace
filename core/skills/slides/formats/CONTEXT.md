# formats
> Children of formats.md: one file per content format a slide can carry.

<!-- routing:start -->
## Routing

| File | Description |
|------|-------------|
| [`animation.md`](animation.md) | Click-by-click builds that show change; in Google Slides a build is a slide sequence (the API has no animation). |
| [`charts.md`](charts.md) | Numbers: chart choice by perception rank, direct labels, one message per chart. |
| [`diagrams.md`](diagrams.md) | Structure and flow: architectures, pipelines, flowcharts; depict the mechanism, not its name. |
| [`formulas.md`](formulas.md) | Equations built term by term, colour per term, symbols next to their meaning. |
| [`infographics.md`](infographics.md) | Composite explainers: chart + diagram + type as one reading path. |
| [`interactivity.md`](interactivity.md) | The room answers: polls, QR, peer instruction moments inside the deck. |
| [`live-code.md`](live-code.md) | Code shown or run live: legibility, pre-recorded fallback, one change at a time. |
| [`papers-and-evidence.md`](papers-and-evidence.md) | Showing results, tables and citations — ours or others' — credibly, one exhibit per slide. |
| [`video.md`](video.md) | Short clips and demos: length, crop, captions, a fallback frame. |
