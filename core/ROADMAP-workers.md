# Workers Roadmap

> Delegation: who else does the work, outside workers and the harness's own subagents alike, and how a task is routed to one. List policy: [/ROADMAP.md](../ROADMAP.md).

## Intent

**🔴 One delegation policy, provider-agnostic, for every worker** (Lucas, 2026-11-26)
*What* — one policy for both layers: the **outside workers** (`core/tools/workers.py`, `panel/ask`, codex, deepseek, agy, opencode, NIM, ollama) and the **harness's own subagents** (Claude Code's Agent tool: `craft-*`, `lead`, `Explore`; each harness's equivalent). A subagent is a route like any other: the same contract, deadline, outcome log and routing rule hold whichever layer runs the task. The policy makes orchestration and routing easy, raises quality and lowers cost. Every item below serves it.
*Why* — across sessions the work narrowed to outside workers alone and the intent was lost (Lucas, 2026-11-26).
*Done when* — "who does this task" is answered by one rule over one log, whichever layer runs it.

**🔴 outside workers: one catalog, one call, then routing** (Lucas, 2026-11-20; values and stages 2026-11-23, panel argon)
*What* — the base is `core/tools/workers.py`, `core/workers.txt` (model × route) and `core/models.txt`. **A contract is the unit** (Lucas, 2026-11-21, panel deepseek+codex+argon) — goal, inputs, `write_paths`, the output, a deterministic done-check (test, exit code, file exists; never the worker's claim), a try limit — reusing craft's loop file; modes `ask` (read-only) and `write`, which returns **one patch** from an isolated copy (`git archive $(git stash create || echo HEAD)` unpacked in scratch; no worktree, `core/hooks/git/SPECS.md` § No worktrees), applied by the caller only after the done-check passes. **v1 in stages, one closed and tested per session, researched first**: **1.1** walking skeleton — one provider, contract → worker → the diff held to `write_paths` → done-check → applied patch → a `core/state/workers.tsv` line with contract, attempt and done-check columns; **1.2** recovery — a failed check feeds its stderr and the rejected diff back once, then escalates down the chain (argon); a task too big comes back **split**, as new list items; **1.3** a second provider through the same call, the proof of agnosticism, and one craft step (code-until-green) on a cheap worker compared with Claude; **1.4** the catalog is a **choice per route** (Lucas, 2026-11-23): a route is one account (Claude Code, agy = Google AI Pro in three quota buckets, `core/workers.txt`, which also serves Claude Opus/Sonnet 5.5, codex = ChatGPT pending the argon comparison, opencode free, NVIDIA NIM free key; openrouter is paid dollars, last resort; ollama local), and each holds **1–4 models chosen by role and canaried**, never two for one job (the `job` column of `core/workers.txt`, filled 2026-11-23; `role` stays the debate's word); `core/models.txt` keeps only those: no per-use price, proven working. `--check` already fails at every close (`core/periodicos.txt`) when a declared id leaves its harness's own listing; left: the refresh that edits the table itself (Lucas's OK) and names new candidates per route, availability from the call log (no CLI exposes the quota left, 2026-11-23), `job` in `--list` and a pick by job (`ask --only` picks by worker today), a coder canary that is a real failing-test loop (panel argon, 2026-11-23), and kimi/dsh routes. **Delegation is adopted where measured**: the orchestrator's tokens to write the contract and check it must undercut doing it alone at equal quality (1.3); a role's prepared worker is a contract template with its context and done-check. Reels [thousand-agents](https://www.instagram.com/reel/Df96hr1Nu5M/) and [loopforge](https://www.instagram.com/reel/Df-vE_vkckX/) match this. How others isolate (agent knowledge, unverified): Claude Code a worktree per subagent; Codex CLI one checkout under an OS sandbox; OpenHands a container per session; aider none, a commit per edit. **v2**: the image worker (Gemini image API first, never local FLUX: RAM); `panel/` split into `workers/<provider>` only once duplication is proven; debate, research and summarizer flows beyond `--debate` (local first: ollama, `code/dobra`, [textfold](https://github.com/chenxiachan/textfold)); a shared board for parallel agents; rerun from a node; specialist SLMs (the local model on narrow verifiable tasks first, fine-tuning only when the log shows volume and a measured misroute); zcode once its CLI has a model (ISSUES `b20261120-zcode-headless-no-model`); routing in three arms measured in `core/experiments/routing.md` (best published, the `levels.txt` rule, laya/jev/small ollama), the main thread's level, ACP and LiteLLM, the "infinite use" local harness. Absorbs `[panel-opencode-zcode]` and `[subagent-watchdog]`; its headless contracts leave `[cross-harness-delegation]`.
*Why* — **constraints**, pass or fail: provider-agnostic (no vendor in an interface or a file; swapping one is swapping a leaf); private (what leaves for another vendor passes `core/tools/secret_law.py`); the worker never touches its done-check nor writes outside `write_paths`; a ceiling per run (tries, timeout, tokens); RAM and disk never broken — broken more than once, swap full on 2026-11-24 (39 orphaned workers); `core/tools/worker_guard.py` admits and contains each spawn. **Order** inside them: reliability (deterministic, reproducible, recoverable) → quality (panels that mediate, research, summaries) → cost (the Claude Code limit first) → simplicity → coverage → speed. Lucas's draft ranked agnostic first; the panel ruled it a constraint, since ranking it first builds five adapters before one patch is proven.
*Done when* — each stage's own: 1.1 a real task goes contract → cheap worker → done-check → applied patch → log line; 1.2 a failed check recovers; 1.3 the same contract passes on two providers; 1.4 `--list` reports a fresh catalog. v2: Lucas picks a router from measured options.

**🔴 A hung worker never stalls its orchestrator** (Lucas, 2026-11-24)
*What* — incident: a docs-ufrpe session on DeepSeek left the orchestrator waiting forever; reproduced 2026-11-24: `panel/ask --debate` ran ~15 min, deepseek hung the full 900 s (its ok calls: p50 16 s, p90 36 s, max 98 s, n=33), and the run printed `panel: no model answered` with **exit 0**, discarding argon's 47 s answer. Fix 1: no verdict → nonzero exit; a debate keeps partial answers and names who was missing. Detection (decided): per-worker deadline = 3× p90 of its ok calls in `core/state/workers.tsv`, floor 120 s, 900 s with no history — deterministic, so the heartbeat rejection in [/ROADMAP.md](../ROADMAP.md) § Rejected holds. Rejected: stall by output growth (a worker that writes only at the end dies healthy), headless harness subagents (argon), notifications only. The same deadline applies to harness subagents (43 logged, all `finished:true`, no incident yet).
*Why* — one hang cost a whole parallel session.
*Done when* — a faked hung worker ends at its deadline, the debate keeps the others' answers, and the exit is nonzero.

**🔴 Every delegation that disappoints or impresses is counted** (Lucas, 2026-11-24; panel argon, option C)
*What* — automatic, categorical and countable, in the same `core/state/workers.tsv`, in two phases: (1) at call end an automatic `check` — `call()` and the caller's validator say ok, timeout, stall, bad-format, empty or infra; (2) the orchestrator's `verdict` (disappointed, met, impressed) plus a `tag`, through a short subcommand that names the call. `work` uses the kinds in `core/levels.txt`. Tags come from a closed `.txt` the agent proposes and grows with use (stall, timeout, wrong-format, hallucinated-file, partial, off-scope, wrong-answer / sharp-catch, fast-correct, beyond-scope). `--list` counts worker × work × tag over all calls, so a rate has a denominator. A model's failure is kept apart from the harness's or the sandbox's: the orchestrator once declared a live job dead because the sandbox's `ps` could not see it — infra, not the model. First cases (docs-ufrpe, 2026-11-24): deepseek timeout on doc-desc (90 s); codex bad-format on doc-desc; agy fig-vision stalled >10 min on two PDFs. Harness subagents log to the same table.
*Why* — routing by evidence needs a log that counts; today a disappointment is remembered only in chat.
*Done when* — `--list` prints worker × work × tag rates for both layers.
