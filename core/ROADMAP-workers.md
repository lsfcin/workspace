# Workers Roadmap

> Delegation: who else does the work, outside workers and the harness's own subagents alike, and how a task is routed to one. List policy: [/ROADMAP.md](../ROADMAP.md).

## Intent

**🔴 One delegation policy, provider-agnostic, in four runnable versions** (Lucas, 2026-11-26; panel argon twice, `outputs/orquestracao-panel{,2}.md`; research `outputs/orquestracao-pesquisa.md`; diagram https://claude.ai/artifact/De1y5RP5c7bmDNjddHVjj7)
*What* — one rule for every worker: outside CLIs (`core/tools/workers.py`, `core/workers.txt`, `core/models.txt`) and each harness's own subagents. **The orchestrator is a role, not a vendor**: delegation is one shell command, `delegate <contract>`, that any harness calls; `delegate/ask` becomes its `answer` mode. **Every role has redundancy, the orchestrator included** (Lucas, 2026-11-26): each `job` in `core/workers.txt` holds routes on two or more accounts, and `--check` fails when one falls to one; the orchestrator's redundancy is the harness map of `[cross-harness-delegation]` in [ROADMAP.md](ROADMAP.md). **A delegation is the primitive and a flow composes them**: `core/flows/` stays the protocol layer (craft's loop file is the contract), and `code/flows` (graph engine) is weighed as the runtime only in v3. Measured premise: delegated work is 2.5% of spend and cache reads are 59% of the bill (`core/experiments/delegation.md`, `output-cost.md`), so the gain is a small orchestrator context, not cheaper spawns.
*Why* — across sessions the work narrowed to outside workers and the intent was lost; trusting a faulty worker is the biggest source of rework (Lucas, 2026-11-26).
*Done when* — "who does this task" is answered by one rule over one log, whichever harness orchestrates.

**Rules every version keeps.** Constraints, pass or fail: no vendor in an interface; what leaves passes `core/tools/secret_law.py`; a worker never touches its checks nor writes outside `write_paths`; a ceiling per run (tries, deadline, tokens); `core/tools/worker_guard.py` admits each spawn (swap broke on 2026-11-24). Order: reliability → quality → cost → simplicity → coverage → speed.
- **Contract** (one file, craft's loop file; `core/tools/delegate/delegation.py`): a YAML frontmatter `goal, work, role, read_paths, write_paths, checks, attempt, return` — `key: value` broke on colons in commands — then `## Context` and, from attempt 2, a bounded `## Last Failure`, since a fresh session cannot retry blind (Lucas, 2026-11-26, panel argon agreeing). Deadline per worker from its log, not the contract (rejected: stall by output growth, notifications only, and `stall` as a `check` value until something detects it — Lucas, 2026-11-26). Stable prefix first (role pre-prompt, return format), the task last, so every provider's prefix cache hits; `read_paths` inline up to ~3k tokens, larger by path to a worker that reads files only, else `blocked`.
- **Status** `ok | blocked | split | fail`: `blocked` names what it searched and asks ≤3 questions; `split` returns subtasks, depth 1. **No self-rated confidence** — verbal confidence is overconfident (Xiong et al. 2024, panel); the worker lists *assumptions*, *unverified claims* and *what it left untouched* instead, and a non-empty list sends it to review.
- **Return modes**: `answer` (≤1.5k tokens, fixed fields first, the middle cut with a pointer to the full file); `artifact` (path + hash + check results; the orchestrator does not read the file); `patch` (one diff from an isolated copy, `git archive $(git stash create || echo HEAD)` in scratch — no worktree, `core/hooks/git/SPECS.md`).
- **Verification stack**, cheapest first, run by the wrapper, never by the worker: (i) checks written before delegating (tests, schema, `write_paths`, links resolve); (ii) a checklist per `work`, scripted where possible; (iii) a reviewer from another vendor sees contract + diff + check output and returns pass/fail + findings; (iv) the orchestrator reads only the findings. (iii) is skipped only with a strong oracle and a good logged rate, and 1 in N skipped runs is still reviewed (spec gaming, panel).
- **Retry only with new signal** (stderr, rejected diff), then escalate cheap → strong → orchestrator.

**🟡 v1 — produce and route**
*Built, unproven* (2026-11-26, branch `feature/delegate-v1a`): `return: artifact` (`core/tools/delegate/produce.py`) — the worker edits an isolated copy (`sandbox.py`, a `git archive` with its own git, never a worktree), the wrapper runs `checks` there, refuses a change outside `write_paths`, retries once with `## Last Failure`, then the next route in a fresh copy; the orchestrator reads only the report (paths, hashes, checks, route) and `core/state/delegations.tsv` logs its size. Ladder, provisional until the table: one route per harness, cheapest first — free → codex → agy → Claude (`glm → sol → sonnet-agy → claude-medium`); Lucas: exhaust codex and agy before any other Claude model, and codex is a coder rung though out of the panel chain. `claude -p` is a route (user settings only, the parent's session id dropped; `--bare` needs an API key). Isolation, metric and ladder are Lucas's picks (2026-11-26, panel argon: economy-first slice; its warning — a failed worker rescued by the orchestrator reading its files costs more than doing it alone, so a failure never returns files). Proof still owed: the T1 tests (`test_produce.py`, delegated to the ladder itself as the first dogfood), one contract green on two providers, ΔC_orch (tokens entering the orchestrator's thread, contract to green) and the leak rate (how often it read `write_paths` afterwards) in `core/experiments/delegation.md`, and one paired A/B (the same task alone and delegated, each in a clean headless session).
*Still to build* — `patch` mode on the same copy; verification (ii)–(iii); the `work` → route chain table as a `.txt` (free → outside subscription → Claude quota; first draft in the diagram § 2); `resume` as a per-route column, used only by multi-turn contracts; a cache canary per route reading `cached_tokens` where the CLI exposes it (panel: the child CLI may inject timestamps and `git status` before our prefix); retry and escalation; a task too big comes back `split` as list items; `job` in `--list` and a pick by job; a coder canary that is a real failing-test loop; kimi/dsh routes; the catalog refresh that edits `core/workers.txt` (Lucas's OK). **`/craft` adopts the contract, in one pass** (audit 2026-11-26, `outputs/craft-audit.md`): delete `core/flows/craft/routing.md` (a second router, its providers dated 2026-07-16 and its ids behind `core/workers.txt`), skill step 1 `opencode models` → `delegate --list`, the Carry's `provider/level-map/chain-deleg` → the contract's fields, each loop spawned by `delegate <loop-file>` with `craft-*` as the `claude` route.
*Done when* — the same contract passes on two providers, a failed check recovers, and one craft step (code-until-green) on a cheap worker is compared with Claude at equal quality — delegation is adopted where the orchestrator's tokens to write and check the contract undercut doing it alone.

**🟡 [orchestrate-by-default] Every plan is built from delegations — once the saving is proven** (Lucas, 2026-11-26)
*What* — after v1's proof only: whatever harness or agent takes a repo (`wos/take`) or enters plan mode drafts its plan as delegation contracts (subagents and outside workers), and a hook reminds it — offered at take and plan, never forced, with the measured saving quoted. Measured with it: the orchestrator × worker matrix — orchestrators {claude, agy, codex} each calling `delegate`, workers {free, codex, agy} — on one contract (Lucas: start runs from agy and from codex too).
*Why* — better results at lower cost; the saving is a small orchestrator context (Intent), and a session that builds alone grows past 100k — this one reached 141k building v1a before its first delegation, which is the case for planning delegation first.
*Done when* — the reminder fires at take and plan in two harnesses, and the matrix is in `core/experiments/delegation.md`.

**🔴 [wos-diet] The proof's workbench is cutting the workspace OS itself, without mercy** (Lucas, 2026-11-26)
*What* — the next session's work: delegated contracts that cut the workspace's own `.md` load — `CONTEXT.md` routing tables, `AGENTS.md`, norms, the gates that force re-reads — first a baseline (tokens at session start and what the context gate makes a session read, `core/experiments/context-window.md`, `core/run tools/wos/session/reads`), then cuts one contract each with the other-vendor reviewer (iii), rules in `AGENTS.md` and `core/norms/` shown to Lucas before they go, then the A/B: one fixed task in a clean session before and after. The same contracts run `--only` on codex (`sol`) and on agy (`flash`, `argon`), since codex and agy are the strongest outside routes and agy may become Claude's main auxiliary (Lucas, 2026-11-26) — measure, do not pick yet. Past analyses of what a `CONTEXT.md` should hold were lost; recover them (`git log -S`) before cutting.
*Why* — the workspace feels heavy: sessions reach 100k fast (this one read seven `CONTEXT.md` through the gate just to run commands). The orchestrator uses the OS natively, so it judges a worker's cut without reading the file — a natural oracle — and every cut shrinks every future orchestrator's context: two results in one.
*Done when* — the session-start and gate-read tokens are measured before and after, the A/B shows the drop, and each worker route's rate on these contracts is logged.

**🟡 v2 — measure, and make a flow when none fits**
*What* — the orchestrator's `verdict` (disappointed, met, impressed), a `tag` from a closed `.txt` grown with use (stall, timeout, wrong-format, hallucinated-file, partial, off-scope, wrong-answer / sharp-catch, fast-correct, beyond-scope) and `rework` (the orchestrator had to redo it — the key metric), through a short subcommand naming the call; widen the TSV (Lucas, 2026-11-26); `--list` counts worker × work × tag for both layers; the reviewer gate by logged rate; a repeated failure becomes one line in the role's pre-prompt, kept only if it passes the logged cases (Ralph "signs", Reflexion). **A flow is drafted when no flow fits** (Lucas, 2026-11-26): from `core/flows/_template.md`, its steps as contracts, adopted with Lucas's OK. First cases (docs-ufrpe, 2026-11-24): deepseek timeout on doc-desc (90 s); codex bad-format on doc-desc; agy fig-vision stalled >10 min on two PDFs.
*Done when* — `--list` prints the rates for both layers, and one drafted flow ran end to end.
