# [ craft | workspace | now ] learn this brain by using it

The one goal a fresh `brain/` ships with, so the dashboard has a row to draw and the format is taught by an instance rather than by a spec. Delete it once a real goal takes its place — done work is deleted and git is the history (`AGENTS.md`).

**ease-start**  
Copy `_template.md` to `brain/goals/<name>.md`, fill line 1 — area, subarea, horizon, title — and one backlog item. Nothing else is required at creation; every other section has a trigger in `../SPECS.md` and waits for it. Then commit: the dashboard redraws itself from the goal files on every commit, so the row you just made appears without anyone editing `GOALS.md`.
